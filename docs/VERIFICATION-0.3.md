# v0.3(fixed) 验证记录

本记录对应插件构建 `0.3.0+codex.20261009-quota-reliable`，标签 `codex-v0.3.0-fixed.18`。显示名称为 **v0.3(fixed)**。当前证据与历史验证分别记录。

## 本次额度更新的验证

- **273 项单元测试全部通过**：执行 `npm test`。新增 10 项覆盖持久连接、断线重试、超时/取消释放、成功数据保留、强刷排队、扫描解耦、账号切换/退出及前台预取、恢复和跨重置显示。
- **9 项 Electron 额度专项检查通过**：执行 `node tests/desktop-audit-smoke.mjs qa-quota-reliable-only --quota-only`。真实渲染器与模拟额度响应验证小数显示、接收时间、逐秒倒计时、断网保留、恢复更新、首次开泡强刷与连续按压不重复强刷；正常退出且无未处理 Promise 异常。
- **真实官方查询的小样本对比**：`node scripts/probe-quota-refresh.mjs` 仅输出耗时、窗口数与脱敏错误类别。成功请求中，旧进程方式约 2.2–3 秒；复用连接后的两次成功读取约 1.4 秒和 2 秒。两种方式均观察到瞬时错误；样本不足以承诺固定延迟或成功率。
- **界面人工检查**：专项截图确认查询失败仍保留原百分比，并显示上次接收时间；恢复成功后显示新的接收时间。日志与截图留在本机，不进入发行包。

本次完整桌面审计在原有测试夹具的音效模态窗口/原生区域断言处未完成；已修正阻挡额度检查的夹具，并单独跑通上述额度专项。后续其他页面断言尚未全部复跑，不能把专项通过写成完整桌面验收。

## 历史版本已运行的验证（本次未全部重跑）

- **263 项单元测试通过**：覆盖配置、隐私、用量、额度直读、强制刷新、DIY API、记账/归档、媒体、安装升级、窗口状态和绘制生命周期。测试生成的 PowerShell 脚本使用带 BOM 的 UTF-8，在含中文的工作目录中也已通过。
- **16 次真实 Windows 原生区域采样**：使用 `GetWindowRgn` / `GetRegionData` 检查气泡关闭中途及快速重开。关闭类移除后仍保留动画需要的绘制边界，动画结束后收缩。

- **关闭画面专项检查**：隔离测试窗口上的屏幕图确认气泡完整淡出。该专项临时将测试窗口置顶以观察动画，因此只证明动画裁剪行为，不作为日常跟随层级或长期稳定性的证明。
- **紧凑菜单 Electron 审计通过**：验证角色回退、APNG 命中、原版 DSH 四段式音效分组、新建音效组、面板保存/取消/Esc、提问与授权等待事件、同排模式与素材包按钮、API/Codex 切换、消费记录、360×320 滚动、位置重置和关闭刷盘。使用 `tests/desktop-audit-smoke.mjs` 与 `scripts/smoke-desktop.mjs`。
- **完整 Windows 桌面烟测通过**：验证原版设置、角色/声音/泡泡/资源、额度与每轮消耗、汇率、透明穿透、原生点击、宿主遮挡、焦点保持，以及 72 步原生跟随移动/缩放。使用 `scripts/smoke-desktop.mjs`。

- **额度及时刷新通过**：服务端测试确认 `refresh=1` 绕过 30 秒快照；桌宠交互回归确认气泡由关闭变为打开时只强刷一次，保持打开后的连续按压不重复请求；Electron 审查验证潮汐卡片的小数百分比、快照时间和重置倒计时。
- **本机安装验证**：完整安装器的运行构建核验和渲染器就绪检查完成；回滚预检可识别对应备份。安装与回滚回执属于用户本机资料，不进入公开包；回滚预检不等于在另一台设备上实际执行了回滚。

专项机制及验收重点见 [绘制生命周期与悬停修复](SURFACE-LIFECYCLE-FIX.md)。本节的测试数量、安装、模式切换观测和屏幕采样属于历史记录，不并入本次额度更新的验证证据。

## 已知测试限制

`scripts/smoke-desktop.mjs` 与 `tests/desktop-audit-smoke.mjs` 现在都以紧凑菜单为准。Windows 原生点击每次先校验目标 HWND 和 PID，再把按下/抬起作为一组系统输入提交，避免用户在测试期间轻微移动鼠标被误判成拖拽。跟随测试逐步检查覆盖层从未成为前台窗口，同时允许用户主动切换到其他应用。

页面 `capturePage()` 或等待全部动画结束后的截图，不能单独证明 Windows 原生窗口在关闭中途没有裁边。历史动画专项曾同时检查真实原生区域与专项屏幕图，本次额度专项没有重跑该原生检查。

## 尚待用户验收

- Windows 日常跟随中的长期显示稳定性、多显示器与不同缩放，以及最小化、还原、睡眠恢复。
- 原场景中的完整淡出、慢速移动到菜单按钮、透明空白点击与文字拖选。
- macOS 实机，含 Apple Silicon / Intel、Spaces、多屏及睡眠恢复。保留 [PR #128](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget/pull/128) 不等于完成 Mac 实机验收。
- 真实订阅额度在完成更多请求后的连续变化、跨重置点刷新和异常网络恢复仍需日常观察；本次已经验证当前 Plus 账号能够直接读取两个窗口。
- 另一台设备上新打包 ZIP 的完整解压、升级保留和必要时的回滚。

短时验证不能证明偶发消失、白块或光标异常已在所有设备根除。Windows 软件合成和遮挡设置仍按兼容措施描述；不将某次专项通过解释为所有显示问题的唯一根因已确定。

## 包与复验

发布附件文件名为：

- `api-balance-whale-v0.3(fixed).zip`
- `api-balance-whale-v0.3(fixed)-source.zip`
- 两个 ZIP 各自的 `.sha256` 文件与 `release-manifest.json`

文件完整性、实际构建内容及散列以本次重新生成的清单为准。材料整理不得通过修改展示名称伪造一次新运行版本，也不得把旧报告改名当成新测试。测试日志、截图、录像和个人回执不放入分发包。

从源码包完整解压后可运行：

```sh
node scripts/check-package.mjs
node --test tests/*.test.mjs
```

Windows 安装预检：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-package.ps1 -CheckOnly
```

这些命令分别检查包与自动测试，不替代另一台设备上的真实安装。用户试装与反馈继续按 [用户测试清单](USER_TEST_CHECKLIST.md) 执行；本次已获发布授权，但未完成的 Mac、长期稳定性和跨重置点额度刷新仍保持待验证。
