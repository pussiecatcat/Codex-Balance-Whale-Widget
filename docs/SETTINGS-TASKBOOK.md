## 2. 完成定义

以下六项全部满足才可声明“设置优化完成”：

1. 一级紧凑，常用操作不需要理解技术参数。
2. 二级独立大窗口分类完整、控件可达，复杂编辑器有可用空间。
3. 每个可配置字段有具体且准确的说明；动态新增的字段同样覆盖。
4. 所有现有能力可达，旧设置不丢失，两窗口显示与存储一致。
5. Agent 配置文档逐字段覆盖，并至少通过实际修改与回读证明能照文档操作。
6. 完成相关自动测试和真实渲染检查；未能覆盖的平台或实机限制明确记录。

“只加侧栏”“把原小弹窗放大”“只有主设置页有说明”“只有字段计数通过”均不满足完成定义。

## T01｜盘点全部配置，建立字段清单

**目标：** 后面调整界面时不会遗漏功能，文档有明确覆盖基线。

### 工作

- 从真实加载路径盘点，避免把未加载的 `dashboard.js` 当成现状。
- 对主菜单、声音、气泡模块、素材、位置、API 表单、API 模型、提醒模板做完整字段清单。
- 区分可配置字段、即时操作、只读状态、缓存、运行时元数据、历史废弃字段。
- 给每个字段或动态字段模式分配稳定 ID，记录标签、类型、单位、取值、默认来源、依赖条件、存储、读写方法、热更新和说明。
- 记录当前音量的实际叠乘／覆盖关系，以及 `bubbleOn`、`turnCostOn`、任务提示音开关的实际组合行为。
- 列出所有原入口迁往新界面的位置。隐藏的旧功能不能悄悄丢弃。

### 交付物

- 完整配置清单（建议放 `desktop/ui/settings-catalog.js` 或单独数据文件；命名可调整）。
- 完善后的 `docs/CONFIGURATION.md`，保留“当前支持／拟新增”标记直至实现完成。
- 功能迁移对照表：旧入口 → 新分类／子页面 → 配置 ID → 验证项。

### 验收

- 每种动态模块都有子字段清单，不能以一个 `bubble` 条目代替整个编辑器。
- 所有字段都能定位真实源码和存储；有疑点标为待核实并在后续实施前解决。
- 没有把 `updatedAt`、任务序号、用量记录等系统状态列为普通用户偏好。

## T02｜独立设置窗口与最小闭环

**目标：** 先验证架构能工作，再迁移全部编辑器。

### 工作

- 新建单实例、普通不透明、可缩放设置窗口及专用页面入口。
- 初始尺寸按方案；根据实际工作区限制尺寸；小屏内容可滚动。
- 菜单、托盘或现有设置入口统一唤起同一窗口。原本只打开 API 表单的入口按语义跳转到对应分类。
- 独立窗口不接入透明挂件的 `shape`、穿透、宿主跟随和位置保存循环。
- 复用本地 `whale://` 资源与现有安全设置，新增页面／脚本加入明确静态路由。
- 按窗口身份限制 IPC：设置窗口只获得需要的配置及窗口能力。
- 选“大小”或其他简单非私密字段，完成读当前值 → 修改草稿 → 保存 → 回读 → 挂件更新 → 重启仍保留的闭环。

### 重点文件

`desktop/main.cjs`、`desktop/preload.cjs`、`desktop/ipc-window.cjs`、`runtime/dispatcher.mjs`；可增加职责单一的窗口管理和设置页文件。

### 验收

- 重复打开不会出现两个设置窗口。
- 缩小／隐藏 Codex 不使正在编辑的设置窗口消失。
- 关闭设置窗口不退出挂件；退出挂件不会遗留设置窗口。
- 设置窗口不出现第二只鲸鱼、第二份任务监控或多余的音效。
- 无权限的窗口／子框架消息被拒绝；挂件专用消息不能因增加窗口而全面放行。
- 一个字段实际保存、回读、更新挂件通过，随后才进入全量迁移。

## T03｜统一配置更新与草稿保存

**目标：** 多入口改同一配置不会被旧快照覆盖。

### 工作

- 复用现有校验与存储格式，建立按键／保存域更新的适配层，统一写入并通知界面。
- 处理 `UiStateStore.set()` 和 `/api/ui-state` 的整份替换语义；不得直接让两个窗口各自周期提交整份状态。
- `.dshw-size.json` 现接口不是安全的部分补丁，按最新数据合并后写入；不能只提交一个字段就把其他设置恢复默认。
- 窗口页面维护已保存快照和草稿；保存仅提交真实修改的字段。
- 草稿期间其他入口改了相同字段，需检测并给出明确处理；其他字段变化不得丢失。
- 声音页跨多份存储的保存保证可解释的失败恢复；保存进行中防止重复提交或关闭造成状态不明。
- 外观预览／试听的撤销和关闭恢复，不能把试听当成保存。
- 已有特殊提醒组合显示“自定义”，只有用户主动选择组合时才改对应开关。

### 验收场景

1. 设置页编辑声音期间，快捷菜单调大小；保存声音后大小保持最新值。
2. 设置窗口改手感，挂件旧 UI 快照循环运行后手感仍保持新值。
3. 取消或关闭未保存页，重新打开仍是原值。
4. 保存过程某一步失败，明确显示失败，保留草稿，回读确认实际状态；成功提示不得提前出现。
5. 未知但有效的其他偏好键不被重建配置覆盖。
6. 重启或重新创建窗口后显示最后一次成功保存值。

## T04｜一级菜单与二级分类界面

**目标：** 完成用户可理解的分层，而非只移动 DOM。

### 工作

- 按方案建立一级 7 类常用项与底部入口；精确参数移到完整设置。
- 完整设置按六类组织，主内容滚动，当前页保存／撤销可达。
- 一级即时生效，二级按页草稿；界面明确保存状态。
- 说明按钮位置统一；完整设置页的控件有短用途描述。
- API／订阅模式按需展示，切换时保留或妥善处理草稿。
- “记录本机 token 与任务状态”在订阅模式也可找到。
- 统一术语：气泡／用量／点击音效／任务提示音；避免“全局设置”等范围不清的名称。

### 验收

- 新用户无需进入高级设置即可换角色、改大小、选择桌面显示方式、关闭点击声音和修改完成提醒。
- 原有各项功能都在迁移表中有实际可操作的新入口。
- 原有角色点击、气泡切换、右键菜单与数据展示不退化。
- 小屏、窗口缩放和长中文文案不造成横向溢出，操作按钮不会被滚动内容遮住。

## T05｜接入完整编辑器

**目标：** 高级用户能够在大窗口内完整配置。

### 工作

- 声音、气泡、位置、素材、API 编辑器逐步提取为可挂载内容，不把整个挂件脚本加载到设置页。
- 保留气泡序列、模块库、随机文本／图片、配色、布局、变量、模型绑定和实时预览。
- 保留角色导入裁切、GIF／APNG、音频裁切与音效组、素材包预览／导入／导出。
- 保留自定义接口、价格增改删、模型模板、手动额度、预警与预算、提醒模板。
- 复杂编辑器在窗口内容区打开，提供明确返回路径，最多保留一个主要编辑层；轻量选择器可以浮层显示。
- 原有私密字段留空保留规则、恢复默认行为继续有效。

### 验收

- 至少用一个代表性复杂气泡实际完成添加模块、改变样式、保存、重开回读。
- 两种模式的气泡序列互不覆盖。
- 使用隔离素材完成导入、选择、预览、包导出；取消裁切／导入不产生误保存。
- API 空白表单保存不清空已有隐藏配置；价格只更新指定模型。
- 手动额度显示来源真实，不能伪装成官方额度；本机 token 不换算成官方剩余 token。

## T06｜逐项说明与 Agent 文档

**目标：** 每个配置既能让人看懂，也能让 Agent 正确修改。

### 工作

- 给所有字段及动态模块字段提供中性圆形 `!`；可聚焦、有可读名称。
- 每条说明回答用途、调法、范围／单位／空值、生效时机；复杂项给例子。
- 说明不能统一写成“调整此项即可改变设置”。禁止用通用兜底文案冒充逐项覆盖。
- API／气泡／素材嵌套编辑器、依赖开关展开的字段、新增模型字段同样纳入覆盖。
- `docs/CONFIGURATION.md` 补全逐字段契约，包括默认值来源和用户值的区别。
- 写出受支持的 Agent 修改流程：定位运行数据目录 → 读取脱敏当前值 → 校验 → 修改 → 通知界面 → 回读 → 行为验证。
- 若现有命令不够，增加最小本地配置命令并使用共享校验；不得开新的远程／HTTP 服务。新增命令先实现再写成可运行示例。
- 更新 README 文档入口，并记录新模块职责及验证命令。

### 文档照做案例

在隔离配置上实际完成并记录：

1. 调整角色大小，其他设置保持不变。
2. 关闭点击声音，保留任务完成提示音。
3. 设置任务用量提示为手动关闭。
4. 修改按压手感和一个事件独立音量。
5. 修改一个气泡文字及颜色，保留其他模块和另一模式序列。
6. 修改一个模型的价格，保留其他模型和隐藏接口字段。
7. 恢复一个指定设置的默认值，不清空素材或账号配置。
8. 修改新用户默认值，已有用户值不受影响（通过隔离新旧配置测试）。

### 验收

- 清单字段 → UI 设置／明确的 Agent 专用配置 → 说明 → 文档条目能够互相对应。
- 逐项人工抽查说明准确性；覆盖数量检查只作为辅助。
- 文档不存在未实现命令、未核对路径、模板变量含义不明或“自行查源码”占位项。
- 说明按钮不会触发表单提交或切换相邻开关；Esc 只关闭最上层浮层，焦点返回原按钮。
