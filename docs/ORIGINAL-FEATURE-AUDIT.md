# DSH 功能报告与 Codex 版逐项对照

基准：用户提供的《DSH小鲸鱼挂件-完整功能解析.md》，其中主要对象为 v0.3.11；第 18 章介绍另一分叉，不能与主线功能混算。审查日期：2026-10-03。

这份对照区分“已有实现”“桌面等价适配”和“平台差异”。有代码并不等于已拿每家服务商的真实账号测试；多服务商请求采用模拟响应测试，不能据此宣称 34 家真实账号全部可用。

## 本次实际补齐

- 恢复峰谷、套餐、会话标签、随机图片等模块，以及五种峰谷样式与分状态配色。
- 每轮提示使用可编辑模块；订阅模式展示 token，API 模式保留观测金额、估算、待记账和未知状态。
- 增加 34 个模板的 DIY API 注册表、独立配置、余额/额度读取、探测、模型匹配、价格估算。
- 每模型独立余额、每日 token、每日估算费用和额度提醒，可分别编辑模块化提醒泡泡。
- 手动额度、按本机 token 扣减的 DIY 额度、每日/每周重置、重新计数基线。
- 余额校正、版本冲突保护、八位小数校验、固定精度运算、过期明细与日汇总归档。
- 修复模型编辑窗口遮挡、编辑参数丢失、清空阈值无法关闭提醒、订阅提醒不触发和过长提示排版。

## 验证范围

- 自动测试：记账、乱序、恢复、额度直读协议、模板/多窗口解析、密钥目的地限制、对账、媒体、安全、工坊、生命周期。
- Windows Electron 实测：模型添加/编辑/清空阈值、原生层级、模块化提醒、保存及实时绑定；包括 150% 缩放。
- 原有界面回归：取消/失败消耗、音效不重放、汇率更新不换随机内容、非法媒体、磁盘满保存失败、480×380 菜单滚动。
- 第三方供应商无真实密钥的接口采用模拟数据测试；未声称线上全部成功。未做 macOS、移动设备实机验收。

不能把“已覆盖主线功能及桌面等价项”说成报告所有分叉、所有设备、所有账号都已逐项实测。上面的平台差异和数据口径属于交付说明，而不是用空按钮假装已经实现。
