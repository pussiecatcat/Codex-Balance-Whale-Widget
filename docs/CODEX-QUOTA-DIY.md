# Codex 额度 DIY 气泡

本地定制版沿用 `For-Codex` 的鲸鱼、菜单、跟随窗口和原有 API 页面。首次使用默认选择「Codex 订阅」；菜单可随时切换到「API 余额」，原有 API 气泡序列和配置仍独立保存。

第一次点击鲸鱼会打开原来的 SVG 气泡，默认显示五小时和每周额度剩余百分比、各自的重置倒计时；来源保留在说明与悬停提示中。气泡打开后继续点击鲸鱼只播放按压与松开效果，不切换也不收起；点击气泡才进入下一泡，最后一泡再点即“点破”收起。订阅气泡不会在五秒后自动消失；API 气泡仍保留原来的关闭时间。

「自定义泡泡」在订阅模式下编辑独立的订阅序列，并提供「5 小时额度」「每周额度」两个模块。可拖动排版、改文字、字号、颜色，也可从模块库复用。模块支持 `{quota_label}`、`{quota_left}`、`{quota_used}`、`{quota_reset}`、`{quota_source}`。API 模式仍编辑原有序列。旧版 `.dshw-bubble.json` 没有订阅序列时，会显示默认额度气泡，不覆盖旧配置。

设置页沿用原版紧凑平铺菜单，保留角色、大小、音效与提示、气泡全局开关、避让滚动条、吸附与翻转、隐藏菜单按钮、资源管理、API 设置和消费记录等可操作项。点击「音效与提示 → 全局设置」会打开可编辑面板：按压/松开音效、音效组、全局音量、每轮消耗泡泡、自动关闭秒数、完成提示音、提示音组和独立音量都可以预览。保存才写入配置，取消、Esc 或点击遮罩会放弃草稿，恢复默认只重置当前草稿。菜单底部的模式按钮可在 Codex 额度与 API 余额之间切换。

订阅与 API 共用原版的点击手感：桌宠只负责首次打开和按压互动，气泡本身负责推进与收起。Codex 目前没有 DeepSeek 原版的提问/审批事件信号，因此没有放入会显示却永远不触发的假开关；任务完成提示、每轮消耗和现有 Codex 任务事件仍按真实事件工作。

挂件先通过本机 `codex app-server` 的 `account/rateLimits/read` 查询当前额度，按窗口时长识别五小时与每周，忽略其他额度池。调用失败时，回退到原有的本机会话 `rate_limits` 记录。两路都没有数据时显示「未观测」；记录过期或重置时间已过时标明过期，不用 token 数推算额度。倒计时每秒更新，打开气泡期间最多每 30 秒重新取一次额度。

已在 Windows 本机安装后用当前 Plus 登录验证 app-server 直接读取：五小时和每周窗口均返回剩余百分比与重置时间。数值会随使用变化，不在文档中固定记录。协议握手、窗口识别、回退逻辑和气泡格式也由自动测试覆盖。

首次安装需要下载 Electron。如果 GitHub 下载停滞，可在执行安装脚本的 PowerShell 会话中先设置镜像（安装仍会校验 Electron 包）：

```powershell
$env:ELECTRON_MIRROR = 'https://mirrors.huaweicloud.com/electron/'
$env:ELECTRON_CUSTOM_DIR = '{{ version }}'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-package.ps1
```
