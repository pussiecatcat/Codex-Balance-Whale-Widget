# 紧凑菜单与原 B 版功能对照

项目曾将菜单改成“概览 / 用量 / 设置”三页 B 版面板。根据实际使用反馈，该面板占地过大，已不再加载。当前界面恢复为上游风格的紧凑平铺菜单，并将重复入口合并。

菜单顶部用一个下拉框切换“Codex 额度 / API 余额”；五小时和每周额度直接由鲸鱼气泡展示。原来独立的“会员额度详情”和“音效与手感”入口已删除；按压、每轮结束、提问和授权的气泡与声音统一收进“音效与提示”。

无有效保存位置时，第一帧即位于右下角。设置 → 外观与位置 →“位置重置到右下角”可主动重置，后续拖动仍会记忆位置。无穷大或负距离的旧锚点不再用于恢复。

| 功能区 | API 余额模式 | Codex 额度模式 |
| --- | --- | --- |
| 鲸鱼气泡 | 当前余额、今日与本轮已观测消费 | 分开的 5 小时与每周剩余百分比、重置倒计时和本轮 token |
| 用量入口 | 今日/近 7 天明细、预警、预算、图表与模型占比 | 本机 token 作为气泡模块和每轮提示，不伪装成官方剩余 token |
| 设置菜单 | 完整保留角色、声音、气泡、位置、资源、接口与消费记录 | 保留通用设置，API 金额专属项自动隐藏 |

没有快照时明确显示未观测，不用示例填充。订阅百分比不是固定 token 配额；本机 token 不含其他设备，缓存/推理可能已包含在输入/输出中。API 小额大于零但不足显示精度时显示“＜0.01”，未知与待记账不会显示成零。

## 保留的原功能

- 外观与位置：角色选择/导入、大小滑块与数字、滚动条避让及宽度、吸附/翻转自定义、隐藏菜单按钮、桌面/跟随切换。
- 声音与气泡：音效选择/导入与原编辑器、主音量、气泡总开关和完整编辑器、每轮提示及关闭时间、任务结束声音；提问与授权提示分别提供气泡内容、声音开关、选音、音量和试听。
- 用量与资源：币种、汇率刷新和说明、资源管理、「素材包导入/导出」及预览/重载、适用时的 DeepSeek 峰谷。订阅额度直接在概览和气泡中显示，不再提供重复的详情入口。
- API 高级设置：自动/自定义接口、字段/换算、配置方案与目录、单模型价格增改删、会话观测开关；继续隐藏已有私密配置。
- API 用量：余额预警、每日预算及提示模板、今日/近 7 天/全部记录、图表、模型占比与原有明细操作。
- 角色点击、拖动、气泡与中性取消提示、托盘和右键入口保持原逻辑。

原控件的事件和保存逻辑保留。合并音效面板使用草稿交易：只有“保存”写入，“取消”、Esc 或点击遮罩都放弃本次修改。

## 验证

1. 分别切到 API/Codex 额度，确认菜单不关闭且不修改登录或密钥。
2. 将角色放到窗口四角、缩小窗口，确认菜单在视口内且最后一项可滚动到达。
3. 在“音效与提示”中修改按压、每轮结束、提问或授权提示，分别验证保存、取消和 Esc。
4. API 模式打开预算、消费记录、图表和 DIY 模型；Codex 模式检查两个额度窗口。
5. Codex 模式完成或取消一次任务，提示只显示 token，不显示 API 金额。

macOS 保留 PR #128 兼容路径，本轮没有 Mac 实机验证。自动 UI 测试中的额度数据属于合成样本；另已在当前 Plus 账号上验证 app-server 能直接返回 5 小时与周窗口。
