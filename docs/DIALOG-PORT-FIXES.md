### 5.1 切换后窗口偏移恢复

用户反馈看不见挂件。现场服务正常，窗口却位于 `x=221,y=33,width=1470,height=845`。旧逻辑仅在宿主未 attached 且尚未应用桌面尺寸时恢复位置；macOS 仍可观测到 Codex 时，常驻桌面窗口的几何偏移不会纠正。调整为在非原生跟随的桌面模式下比较实际窗口与主屏工作区，仅在发生偏移时恢复尺寸和位置，不反复隐藏/显示。

### 5.2 额度持续灰色的原因与恢复

现场正式 Electron 进程的 PATH 只有 `/usr/bin:/bin:/usr/sbin:/sbin`，未设置 `CODEX_CLI_PATH`；旧的 macOS 查找逻辑直接返回 `codex`。完整复现同样的环境后，两次启动查询程序均报 `ENOENT`。交互终端有显式 CLI 路径，真实查询可以成功，因此此前终端查询成功不能证明正式后台可查询。

修复 `runtime/codex-rate-limits.mjs` 的 macOS 可执行文件发现：保留显式路径与 PATH 中 CLI 的优先级，缺失时寻找用户或系统 Applications 下已安装应用自带的原生 CLI。无需修改系统 PATH、LaunchAgent 或凭证。点击刷新与对话完成后的刷新入口原本存在，本次未改动其触发规则，也未用更新旧记录时间或取消灰色提示来掩盖失败。
