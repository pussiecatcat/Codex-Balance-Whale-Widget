# 大肥鱼设置优化方案

状态：方案稿，尚未实施。日期：2026-10-03。目标分支：`对话框优化`。

## 1. 要解决的问题

用户打开设置后，应能快速完成“换角色、调大小、决定是否出声和提醒”。不熟悉的选项能够点开说明；复杂定制有足够大的操作空间。用户也可以用自然语言让 Agent 修改任意支持的配置，而不必自己找文件或理解参数。

### 用户明确提出的要求

1. 一级保留基本配置，复杂选项进入二级。
2. 二级打开更大的完整设置窗口。
3. 每项设置提供可点击的感叹号说明：是什么意思、怎么改。
4. 项目文档能够引导 Agent 直接定位和修改所有可配置项。
5. 本轮只写方案和任务书，由其他 Agent 实施。

### 本文的推荐方案

**一级保留轻量快捷菜单，二级使用独立的普通设置窗口，约 960 × 720；左侧分类、右侧配置。** 设置窗口可以移动、缩放，打开时不受鲸鱼所在角落或 Codex 窗口大小限制。

独立窗口是本方案的技术建议，尚未实施。代价是需要处理挂件与设置窗口之间的配置同步；收益是完整设置真正有稳定的空间，也不必扩大透明挂件的鼠标拦截区域。若后续用户要求先用同窗口大弹层，须调整窗口和验收章节，不能把两种效果混为一谈。

## 2. 当前代码中已确认的情况

- 当前加载的是紧凑菜单。`desktop/ui/widget.html` 没有加载旧的 `dashboard.js`。
- `docs/DASHBOARD-B.md` 记录了大面板因占地过大被撤回；这次保留日常菜单的小尺寸，仅主动进入二级时打开大窗口。
- 角色、大小、气泡、滚动条避让、吸附／翻转、资源管理等主要在 `assets/whale-widget.js` 中。
- `sound-settings.js` 将声音入口合并，但按钮叫“全局设置”，实际只控制声音和提示。
- API 表单在 `widget.html` / `client.js`，另有独立 API 模型编辑器。
- 部分配置存文件，部分先存 `localStorage` 再保存到 `ui-state.json`。当前 UI 状态保存是整份替换，多窗口直接复用会有覆盖风险。
- 桌面主窗口透明、无边框，并实现穿透和跟随。它不能直接当作普通设置窗口使用。

以上为静态代码核对；本轮未启动挂件、未做界面实测。

## 3. 一级：快捷菜单

目标：日常操作集中在约 7 行，普通桌面尺寸下不滚动。缩小屏幕时允许滚动，底部入口始终可达。

| 项目 | 交互 | 说明 |
| --- | --- | --- |
| 查看数据 | Codex 额度 / API 余额 | 保留现有模式；这是显示来源，不更改账号登录 |
| 角色 | 小缩略图＋当前角色，点击选择 | 导入入口放进选择器尾部，主菜单不单独占一行 |
| 大小 | 一个滑块 | 显示“小—大”；精确值放完整设置，不把现有 1–20 显示刻度误写为底层 scale |
| 桌面显示 | 跟随 Codex / 常驻桌面 | 两个选项旁分别用一句话解释 |
| 点击音效 | 开关 | 仅控制点击／松开声音，不暗示能够关闭任务提示音 |
| 完成提醒 | 关闭 / 仅气泡 / 气泡和声音 | 这是常用组合；已有不同组合或自定义状态显示“自定义”，打开菜单不能擅自归一化 |
| 气泡 | 显示气泡开关 | 关闭时说明相关提醒可能不再可见，不自动修改声音偏好 |

菜单底部：`高级设置…` 和 `移回右下角`。API 消费记录属于数据查看入口，按当前模式保留，不混入高级参数。

**一级项修改后直接保存并反馈结果。** 写入失败要恢复显示或明确显示失败，不能看起来成功却未保存。

不在一级展示：吸附百分比、滚动条像素、各事件独立音量、模板变量、接口 JSON 路径、token 单价、素材包管理。

## 4. 二级：完整设置窗口

### 4.1 窗口行为

- 标题“大肥鱼设置”，建议初始 960 × 720；推荐最小 760 × 560。实际尺寸必须限制在显示器工作区内，小屏允许更小并改为纵向布局。
- 单实例：重复点击只将已有设置窗口置前，不叠加第二个窗口。
- 普通不透明系统窗口，有原生标题栏与关闭按钮；不永久置顶、不透传鼠标，不套用挂件的原生裁切区域。
- Codex 缩小、移动或暂时隐藏时，已打开的设置窗口仍可操作；退出大肥鱼服务时一并关闭。
- 左侧分类固定；右侧内容滚动，标题、保存状态和当前页操作区保持可达。
- 设置窗口不产生第二只鲸鱼，不重复启动任务监控、声音播放或余额轮询。

### 4.2 页面结构草图

```text
┌ 大肥鱼设置 ──────────────────────────────────────────┐
│                  │ 声音与提醒                        │
│ 外观与显示       │ 决定什么时候出声、显示什么提醒     │
│ 声音与提醒       │                                    │
│ 气泡内容         │ 点击时播放声音        [开关]  (!)  │
│ 位置与交互       │ 点击音效              [选择]  (!)  │
│ 素材管理         │ 点击音量              [滑块]  (!)  │
│ API 与用量       │                         [试听]     │
│                  │ 任务完成提醒                       │
│                  │ 提示方式              [选择]  (!)  │
│                  │ 显示多久              [选择]  (!)  │
│                  │                                    │
│                  │ ▸ 分别设置按下、松开等声音         │
│                  ├────────────────────────────────────┤
│                  │ 有未保存修改   [撤销] [保存更改]   │
└──────────────────┴────────────────────────────────────┘
```

这是结构草图，不是已经实现的界面。配色沿用鲸鱼的蓝紫／浅色系，常规正文建议 14px 左右；分类名称、控件标签与说明层级清晰。

### 4.3 分类与设置归属

| 分类 | 直接展示 | 需要时展开的精细设置 |
| --- | --- | --- |
| 外观与显示 | 角色选择／导入、大小、跟随／常驻、数据显示来源 | 精确大小值；不新增本来不存在的主题、透明度等功能 |
| 声音与提醒 | 点击声音、音效选择、音量与试听；完成提醒方式、提示音、停留时间 | 按压手感；按下／松开／完成／取消／失败各自的音色与音量；兼容已有特殊组合 |
| 气泡内容 | 显示气泡、当前模式预览、编辑内容入口 | 点击顺序、并列气泡、模块、文字样式、图片／随机内容、模板变量、每轮提示样式 |
| 位置与交互 | 自动贴边、位置复位、菜单按钮显示 | 各边距离、比例／像素模式、朝向翻转线、滚动条避让 |
| 素材管理 | 角色／气泡图片／音效分类列表、导入、预览 | 裁切、音频片段、音效组、素材包导入／导出；沿用现有删除确认 |
| API 与用量 | API 接口状态、显示币种、余额预警、每日预算 | 自定义接口字段、换算、配置方案、模型价格、API 模型、手动额度、提示模板 |

Codex 额度模式隐藏 API 专属编辑控件；保留“数据显示来源”的可见入口以便切换。当前处于 API 分类时若切回 Codex 额度，应处理未保存草稿并返回有效分类。

“记录本机 token 与任务状态”同时影响订阅和 API 使用，放在“声音与提醒”的相关说明或“外观与显示”的数据设置中，不能随 API 专属区一起隐藏。

### 4.4 布局和用词

- 每行左侧“名称＋一句用途”，右侧控件与 `!`。
- 二级不把所有参数一次铺开。大窗口用于分组、解释和预览，仍按任务逐步展开。
- 气泡与素材这种需要画布的编辑器，在设置窗口内进入宽内容页，显示“返回气泡内容／素材管理”。避免连续叠出第三、第四个小弹框。
- 色板、角色下拉、试听、说明可以作为轻量浮层；复杂表单用完整内容页。
- “全局设置”改为准确的具体名称；“复位”改“移回右下角”；“每轮消耗提示”改“任务结束后显示用量”。
- 同一数值可以在一级和二级出现，但必须使用相同配置来源，保持同步。

## 5. 每项设置的感叹号说明

### 5.1 展示规则

圆形 `!` 表示“查看说明”，使用中性色，不使用红色警告样式。点击后弹出内容卡，允许点击、键盘打开，Esc 关闭并把焦点还给原按钮。说明卡不依赖悬停，文本可选择复制，不遮住对应设置的操作。

每个可配置字段都必须有说明。可以将名称与含义相同的一组重复事件控件复用同一个说明模板，但内容必须带具体事件名称和实际规则。

### 5.2 说明内容模板

1. **有什么用**：对用户可见的结果。
2. **怎么调**：每个选项的区别、单位、范围、空值或特殊值。
3. **什么时候生效**：立即生效、保存后生效或需要重新加载。
4. **适合怎么选**：确有推荐值时给推荐及原因，不把默认值当作适合所有人的建议。

复杂项可追加一个具体例子。说明正文不放源码路径、IPC、JSON 键等开发细节；这些放配置文档。

### 5.3 说明示例

**任务结束后显示多久**

- 用途：控制任务完成后的用量气泡停留时间。
- 调整：可选 5 秒、10 秒、手动关闭；自定义时输入秒数。当前编辑器支持 0–3600 秒，其中 0 表示手动关闭。
- 生效：保存后用于下一次任务完成提示。
- 建议：先用 5 秒；经常来不及看可以选手动关闭。
- 边界：不因此改变点击角色后查看订阅额度气泡的停留行为。

**避开右侧滚动条**

- 用途：让挂件右侧留出空间，减少遮挡滚动条。
- 调整：开启后输入距离，单位像素；17px 是现有回退值，0 表示不留距离。
- 生效：保存后重新摆放挂件；关闭时保留已填写距离，便于再次启用。

**密钥环境变量名**

- 用途：告诉挂件从哪个已有环境变量读取密钥。
- 调整：填写变量名，例如 `MY_API_KEY`；不填写密钥本身。留空的实际行为按当前表单的“保留已有值／使用默认”状态说明。
- 生效：保存后按该变量名查找。更换域名时必须使用对应服务专用的变量。
- 边界：这个输入框不会创建环境变量；不能承诺仅填名称就连接成功。

## 6. 保存、预览与恢复

### 常用菜单

即时保存；保存失败有明确反馈。更新设置窗口中相应字段时，保留该窗口中其他未保存的修改。

### 完整设置

- 按页维护草稿，切换分类保留草稿；当前页有“撤销修改／保存更改”。不做跨所有分类的“全部保存”。
- 一项设置只归一个保存域，避免同一个底层字段同时由多个页的旧草稿覆盖。
- 试听、角色／大小预览可以即时预览，但必须明确为预览；撤销或关闭时恢复已保存值。
- 保存成功后同步挂件、快捷菜单和当前设置页，不要求重启整个应用；确实需要重新加载的设置要逐项说明。
- 保存失败保留草稿并显示具体原因。多个现有存储参与同一页保存时，必须明确处理部分失败并测试，不得提前显示“已保存”。
- 关闭窗口时有未保存修改，提供“继续编辑／放弃未保存修改”；不把关闭操作当作保存。
- “恢复本页默认”先改变草稿，再保存才生效；不清空素材、账号、API 私密配置或其他分类。
- 素材导入／删除、切换运行方式、重置位置属于即时操作，应在按钮旁说明并与页草稿分开；删除继续沿用用户确认。

## 7. Agent 可修改配置的文档契约

文档不是仅列出界面名称。必须保证每一个实际可配置字段和动态模块都能沿下面链路定位：

`用户说法 → 稳定 setting ID → 当前值／默认值 → 保存位置 → 修改入口 → 验证结果`

每条配置包含：中文名称、类型／单位／范围、默认值及来源、适用模式、依赖条件、空值语义、实际存储键、允许的修改方式、热更新方式、验证步骤和恢复方式。

- 页面文案／说明与文档共用配置清单，或建立逐字段覆盖检查，避免两套说明逐渐不一致。
- 动态模型、气泡、素材不能写成“见源码”即算完成；需要子字段契约和有代表性的修改示例。
- Agent 改当前值与改新用户默认值必须有不同操作示例。
- 运行中的应用通过受支持的配置入口修改；不要直接改文件后与旧窗口快照争写。
- 不因提供 Agent 修改入口而放宽密钥、删除、部署等授权边界。
- 可复用现有 `serviceRequest`；是否增加专用命令由实施 Agent 判断。若增加，只为可验证的配置读写服务，不另建网络服务。

## 8. 技术建议与必须守住的边界

1. 新增普通设置窗口，复用现有本地协议和配置校验。设置页使用专用入口，不完整加载 `whale-widget.js` 再把鲸鱼隐藏。
2. 按需要提取编辑器和配置适配层，限制在设置相关路径，保留现有数据格式。先完成一个真实设置从读取到保存、回读、挂件更新的闭环，再扩展。
3. 挂件专用的鼠标穿透、裁切、跟随、按压和定时 UI 快照只作用于挂件窗口。
4. IPC 校验按窗口与操作能力区分；设置窗口不能发出挂件裁切、鼠标穿透、宿主跟随等任意控制指令。
5. 配置由统一写入者按键更新并通知界面，避免 `ui-state.json` 的旧整份快照覆盖新设置。旧设置读取兼容；不要改数据库或执行数据迁移。
6. 后台可能已产生新的设置值，草稿保存只能提交本页确实修改的字段；冲突需保留用户修改并给出明确处理方式。
7. 精细音量目前有多个层级。先建立真实计算关系，再决定如何呈现；不要直接把现有按压音量改名为“总音量”。

具体任务、文件边界与验证要求见 [实施任务书](SETTINGS-TASKBOOK.md)。
